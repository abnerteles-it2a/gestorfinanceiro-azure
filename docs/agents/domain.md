# Domain docs

## Layout

Contexto único: CONTEXT.md na raiz e decisões em docs/adr/.

## Consumer rules

- Antes de explorar, leia CONTEXT.md e os ADRs pertinentes ao trabalho.
- Se CONTEXT-MAP.md existir futuramente, siga seus links para os contextos relevantes.
- Use os termos do glossário em tickets, hipóteses, propostas e testes.
- Ao contrariar um ADR, identifique a decisão e explique a razão para reconsiderá-la.
- Quando documentos de domínio estiverem ausentes, prossiga. Crie-os apenas quando termos ou decisões reais forem resolvidos.
